# HWAE Campaign Ports

Custom campaigns from the original **Hammerwatch**, ported to **Hammerwatch Anniversary Edition**.

Conversions are done with [HammerwatchToAnniversaryCampaignConverter](https://github.com/bennpham/HammerwatchToAnniversaryCampaignConverter).

## Layout

| Folder | Contents |
| --- | --- |
| [original/](original/) | The original Hammerwatch campaign files, as unpacked |
| [converted/](converted/) | The converted Anniversary Edition campaigns |

Each campaign lives in a folder with the same name under both directories (e.g. `original/piratecove` → `converted/piratecove`).

## Finding original campaigns

- **Steam Workshop:** most campaigns can be downloaded from the Hammerwatch Workshop.
- **Not on the Workshop:** check the old Hammerwatch forum's custom content board via the Wayback Machine:
  <https://web.archive.org/web/20210116231406/http://hammerwatch.com/forum/index.php?board=2.0>
